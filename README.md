# 轻跃：微信小程序版跳一跳

独立的小程序项目，无需安装依赖、服务器或图片素材。

## 运行

1. 打开微信开发者工具，导入本文件夹 `wechat-jump`（包含 project.config.json 的目录）。
2. 选择小程序项目，填写自己的小程序 AppID；本地体验可选择工具提供的测试号/游客模式（以工具可用选项为准）。配置中的 touristappid 仅供本地试用。
3. 编译后，在模拟器画面中按住、松开即可操作。有自己的 AppID 后可通过预览在手机上体验。

## 玩法

- 按住游戏画面蓄力，松开后自动朝下一平台跳跃。
- 蓄力时显示平台中心靶心和随力度移动的预计落点准星：棕色表示未落台，蓝色表示可落台，绿色表示对准中心。看到“已对准中心，松手！”即可释放。
- 每次产生下一台阶时，均匀随机生成 0.3～1 的距离系数。1 对应当前屏幕内较远的位置，0.3 是该距离的三成；底部显示系数（四舍五入至两位小数）。较近的台阶会缩小，避免重叠。
- 距离越远需要蓄力越久，约 0.324～1.08 秒对应最短至最远台阶，蓄力条在 1.2 秒达到上限。以绿色落点准星为准。
- 落在下一平台得 1 分，落在中心附近得 2 分；落回当前平台可以继续尝试。
- 跌落后重新开始，个人最高分保存在当前设备。
- 记分牌显示本局得分、个人最佳和剩余复活机会，右上角显示已跳过的台阶数。
- 奖励按轮随机安排：每轮随机取 1～6 个新台阶，在其中随机选择 1～2 个不同台阶放置金色「+」；只有 1 个台阶的轮次放置 1 个奖励。每轮独立随机，落回原台阶或复活不刷新奖励。落台即可领取一次，可累计。跌落时自动消耗一次，在最后成功站立的平台中心复活，保留分数与下一目标；没有机会则本局结束。每个奖励只能领取一次，重新开始会清空本局复活机会并重新生成奖励安排。
- 切到后台会取消蓄力并暂停动画，返回后继续。

## 文件

`pages/index/index.js` 管理画面、输入和动画；`physics.js` 管理跳跃距离和落点判定；WXML/WXSS 管理计分、蓄力条和结束提示。触摸事件由页面统一接收，按钮单独处理；不足 100 毫秒的误触不会起跳。失败仅显示底部提示，不弹出遮挡游戏的窗口。

这是普通微信小程序的 Canvas 2D 实现，尚未接入排行榜、登录、音效或微信小游戏专用能力。上架前需要替换为自己的 AppID，并在微信开发者工具和真机上验证。
